# Ресурсы

## Поиск источников

**Русскоязычные:**
- eLibrary — elibrary.ru
- КиберЛенинка — cyberleninka.ru
- Национальный корпус русского языка — ruscorpora.ru

**Зарубежные:**
- Google Scholar — scholar.google.com
- Semantic Scholar — semanticscholar.org
- ACL Anthology — aclanthology.org (компьютерная лингвистика)
- arXiv — arxiv.org (разделы cs.CL, cs.LG)
- DOAJ — doaj.org (открытые журналы)

## Данные и материалы

- HuggingFace Datasets — huggingface.co/datasets
- Открытый корпус — opencorpora.org
- Проект «Тайга» — корпус русского языка
- Zenodo — zenodo.org (публикация и поиск научных данных)

## Оформление

- Требования к ВКР — размещаются в СДО
- ГОСТ Р 7.0.100–2018 — библиографическая запись
- ГОСТ Р 7.0.5–2008 — библиографическая ссылка
- Zotero, Mendeley — управление библиографией

## Апробация

Формы апробации, применимые к работам этой дисциплины:
- студенческие конференции университета;
- «Неделя науки» СПбПУ;
- профильные молодёжные конференции по лингвистике и цифровым гуманитарным
  исследованиям;
- публикация артефакта: репозиторий, описание корпуса, демонстрационная версия.
