# Образцы заполненных документов

В папке размещаются обезличенные образцы документов из работ прошлых лет.

Образцы даются для ознакомления со степенью подробности и характером
формулировок, а не для заимствования. Материал, тема и метод в каждой работе
свои.

## Что предполагается разместить

| Файл | Документ |
|---|---|
| `паспорт_трек_А.md` | Паспорт работы, разработка |
| `паспорт_трек_Б.md` | Паспорт работы, исследование с данными |
| `паспорт_трек_В.md` | Паспорт работы, без кода и данных |
| `программа_исследования.md` | Программа исследования |
| `процедура_анализа.md` | Процедура анализа с системой категорий |
| `границы_исследования.md` | Раздел «границы» с разбором формулировок |
| `рецензия.md` | Рецензия с замечаниями в проверяемой форме |

Образцы размещаются с согласия авторов, без указания имён и с изменением
темы, если работа не защищена.
