# Чек-листы вех

Проходите по списку до занятия. Каждый пункт — либо да, либо нет.

---

## Веха 1 — 26 сентября. Материал

**Общее для всех треков**

- [ ] Тема согласована с научным руководителем
- [ ] Заполнен паспорт работы
- [ ] Составлен обзор источников: не менее 15 позиций с аннотациями
- [ ] Заполнен реестр рисков
- [ ] Сдана программа исследования: объект, предмет, цель, задачи, гипотеза
- [ ] В программе есть раздел «границы исследования», не менее пяти пунктов
- [ ] Составлен календарный план до защиты
- [ ] Материал собран и находится у вас
- [ ] Заполнено описание материала: состав, объём, источник, правовые основания
- [ ] Прочитаны десять случайных единиц материала
- [ ] Найдены и записаны три проблемы в материале
- [ ] Описана процедура анализа

**Дополнительно по трекам**

- [ ] **Трек А:** проверен доступ к необходимым инструментам, библиотекам, вычислительным ресурсам
- [ ] **Трек Б:** проверена сопоставимость единиц материала между собой
- [ ] **Трек В:** система категорий анализа определена, категории различимы на примерах

**Правовая сторона.** Если материал содержит сведения о людях — интервью, записи занятий, студенческие работы, переписка:

- [ ] Описан порядок получения согласия
- [ ] Описан способ обеспечения анонимности
- [ ] Определено, что из материала может быть приведено в тексте работы

**На занятии:** экран с реальными файлами материала.

---

## Веха 2 — 24 октября. Пилот и взаимное рецензирование

**Пилот пройден, если верны все три положения:**

- [ ] Цепочка исследования пройдена целиком — от постановки задачи до вывода
- [ ] Пилот выполнен на реальном материале, а не на подобранных примерах
- [ ] Получен предварительный результат, пусть и на малой выборке

**Готовность материалов**

- [ ] Описание методики достаточно подробно, чтобы процедуру повторил другой человек
- [ ] Результаты пилота зафиксированы письменно
- [ ] Отмечено, что в ходе пилота пришлось изменить в первоначальном замысле
- [ ] Обновлён реестр рисков
- [ ] Задачи, отмеченные как обязательные, отражают текущее понимание работы

**К рецензированию**

- [ ] Материалы оформлены так, чтобы их можно было понять без ваших пояснений
- [ ] Указан объём и состав рассмотренного материала
- [ ] Обозначено, какой результат получен и на каком основании

**На занятии:** демонстрация пилота 5 минут, затем рецензирование чужой работы.

---

## Веха 3 — 5 декабря. Защита задела

**Содержание**

- [ ] Замечания рецензента рассмотрены: приняты и учтены либо отклонены с обоснованием
- [ ] Написан черновик первой главы
- [ ] Проверена согласованность: правки в одном разделе не противоречат другим
- [ ] Результаты пилота описаны с указанием ограничений
- [ ] Определён план работы до защиты ВКР с датами
- [ ] Назван основной риск и план действий при его наступлении

**Апробация** (не менее одного пункта)

- [ ] Подготовлены тезисы или доклад
- [ ] Результат представлен экспертам или предполагаемым пользователям
- [ ] Опубликован артефакт: репозиторий, демонстрационная версия, описание материала

**Документы**

- [ ] Заполнен отчёт о заделе
- [ ] Заполнена рефлексия
- [ ] Материалы доступны по ссылке, указанной в паспорте работы

**Доклад**

- [ ] Уложен в 8 минут, проверено с таймером
- [ ] Демонстрация подготовлена в варианте, не требующем интернета

**На занятии:** доклад 8 минут, вопросы 4 минуты, общая рефлексия.
